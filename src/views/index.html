Tentang Saya

Yuk Mengenal diri saya

Halo! Saya Nuriskha Ainun Fahmi, seorang Mobile Developer yang penuh semangat dalam menciptakan aplikasi mobile yang inovatif dan user-friendly. Dengan latar belakang yang kuat dalam pengembangan aplikasi Android dan iOS, saya terus belajar dan berkembang untuk menjadi seorang Fullstack Developer yang handal.

Saya percaya bahwa teknologi adalah alat untuk menyelesaikan masalah dan membuat hidup lebih baik. Setiap proyek yang saya kerjakan adalah kesempatan untuk belajar sesuatu yang baru dan memberikan nilai bagi pengguna.

Saat ini, saya fokus pada pengembangan aplikasi mobile menggunakan teknologi modern seperti Flutter, Kotlin Compose, React Native, dan native development. Saya juga aktif belajar tentang backend development, cloud computing, dan best practices dalam software engineering.
